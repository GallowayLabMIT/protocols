===============
DNA wash buffer
===============

This wash buffer can be used for the :doc:`DNA cleanup </protocols/cloning/dna_cleanup>` washes or 
the second :ref:`miniprep <miniprep>` wash.

DNA wash stock solution (5x)
============================

This is stored in a bottle on the shelf above the large thermocyclers.

====================    =============================
Ingredient                  Amount (per 80 mL) 
====================    =============================
80 mM NaCl                  0.374 g
8 mM Tris-HCl               0.101 g
Water                       80 mL
HCl to pH 7.5
====================    =============================

DNA wash buffer
===============

====================    =============================
Ingredient                  Amount (per 100 mL) 
====================    =============================
5x stock solution           20 mL
Ethanol                     80 mL
====================    =============================
