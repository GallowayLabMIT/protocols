===============================
qPCR for library quantification
===============================

To quantify genomics libraries (i.e., measure concentration), we perform qPCR
on two dilutions of each sample. We use the NEBNext Library Quant Kit (NEB product code todo). 
This protocol is adapted from the one provided with the kit :download:`here </_static/files/neb_library_quant_kit_manual.pdf>`.
